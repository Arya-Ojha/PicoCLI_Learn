# Triage labels

The `triage` skill uses a fixed set of roles to classify issues. Each role maps to a label string.

## Labels

| Role | Label string |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Wontfix | `wontfix` |

These are the default labels — each label string equals its role name. Apply them as-is; do not create duplicate labels under different names.
