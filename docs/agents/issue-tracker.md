# Issue tracker

This repository tracks issues as local markdown files. There is no external issue tracker.

## Where issues live

- Issues live as files under `.scratch/<feature>/` in this repository.
- Each issue is a single markdown file within its feature folder.

## How to create an issue

- Decide the feature folder (`.scratch/<feature>/`) the issue belongs to.
- Create a file representing the issue in that folder.

## How to refer to issues

- Refer to issues by their path under `.scratch/<feature>/`.
- Skills such as `to-tickets`, `triage`, and `to-spec` read from and write to this location.

## PRs as a request surface

Off. External pull requests are not part of the triage queue.
